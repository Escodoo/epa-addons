This module extends the functionality of Attendance Sheets to support a tier
validation process.

**Table of contents**

.. contents::
   :local:

Configuration
=============

To configure this module, you need to:

#. Go to *Settings > Technical > Tier Validations > Tier Definition*.
#. Create as many tiers as you want for Attendance Sheet model.

Usage
=====

To use this module, you need to:

#. Create an Attendance Sheet triggering at least one "Tier Definition".
#. Click on *Request Validation* button.
#. Under the tab *Reviews* have a look to pending reviews and their statuses.
#. Once all reviews are validated click on *Approve*.

Additional features:

* You can filter the Attendance Sheets requesting your review through the filter *Needs my
  Review*.
* User with rights to approve the Attendance Sheet (validate all tiers that would
  be generated) can directly do the operation, this is, there is no need for
  her/him to request a validation.
